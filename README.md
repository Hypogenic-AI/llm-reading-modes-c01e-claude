# "Modes" in LLM Reading

> Are diverse "modes" of text production — authorship, AI vs. human, register,
> keyboard-layout typo patterns — represented as linearly decodable, geometrically
> disentangled latent variables in the hidden states of a mid-size LLM?

This repository builds a unified pipeline that probes **Qwen2.5-1.5B** last-token
hidden states for four very different production-mode signals and tests whether
they coexist in the residual stream as orthogonal directions.

## Key findings

- **Every mode is linearly decodable.** Peak per-mode accuracy:
  ai_vs_human 99.3% · register 99.8% · authorship (7-class) 79.2% · QWERTY-vs-Dvorak typo 74.5%.
- **Modes are near-orthogonal.** Pairwise cosine between mode directions in
  the hidden-state geometry has max |cos| = 0.18 (register ↔ authorship).
- **Cross-mode probe transfer is mostly chance**, with one striking exception:
  register → ai_vs_human at 0.74 — quantifying ChatGPT's well-known
  formal-register bias inside the latent space.
- **Layer profiles differ by mode type:** content-frame modes (register,
  ai_vs_human) saturate by L≈4; authorship grows monotonically across the stack;
  surface-token modes (typo) emerge only in the *final* layers.
- **TF-IDF beats the neural probe** for authorship (0.96 vs 0.79) and typo
  (0.92 vs 0.74), but the probe wins for ai_vs_human (0.99 vs 0.88). The
  comparison highlights that the neural probe captures **geometric** structure
  (orthogonality, transferability) that surface features cannot.

See **[REPORT.md](REPORT.md)** for full results, figures, and discussion.

## How to reproduce

```bash
uv venv && source .venv/bin/activate && uv sync          # ~1 min
python src/build_corpora.py                              # builds data/chunks.parquet
                                                         # (calls OpenAI for register pairs;
                                                         #  cached in data/register_cache.jsonl)
python src/extract_embeddings.py --batch_size 32 \
       --Ns 32 64 128                                    # cache/embeddings.npz (~2 GB)
bash src/run_remaining.sh                                # parallel probes (register, typo)
# authorship + ai_vs_human can be run the same way:
python src/probe.py --modes ai_vs_human --layer_stride 2 \
       --output_suffix _ai_vs_human
python src/probe.py --modes authorship  --layer_stride 2 \
       --output_suffix _authorship
python src/merge_and_finalize.py                         # baselines, transfer, geometry, plots
```

Hardware tested: 1× NVIDIA RTX A6000 (model forward) + multi-core CPU (probes).
Wall-clock: ~3.5 h end-to-end.

### Environment

- Python ≥ 3.10
- `uv` for dependency management (lockfile in `uv.lock`)
- HF download access (Qwen2.5-1.5B is open; no HF token required, though one
  speeds up downloads)
- `OPENAI_API_KEY` for the **register** mode corpus generation (~$2)
